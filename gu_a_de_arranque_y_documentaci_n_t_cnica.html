🦷 Dentify ERP - Manual de Ejecución y API

Guía de comandos para el terminal y documentación técnica de arquitectura.

🚀 Guía de Arranque Rápido

Para levantar la aplicación completa debes ejecutar dos terminales independientes:

1. Servidor Backend (Flask + SQLite)

Paso 1: Navega a la carpeta del backend desde la raíz del proyecto:

cd backend

Paso 2: Activa el entorno virtual de Python:

.\venv\Scripts\Activate
# Nota: Si tu carpeta se llama .venv, usa: .\.venv\Scripts\Activate

Paso 3: Lanza el servidor en modo desarrollo:

python run.py

URL local del backend: http://127.0.0.1:5000

2. Servidor Frontend (React + Vite + TypeScript)

Paso 1: Abre una segunda terminal y navega a la carpeta del frontend:

cd frontend

Paso 2: Inicia el servidor de Vite:

npm run dev

URL local del frontend: http://localhost:5173

⚡ Backend: Endpoints API

Todas las rutas responden en formato JSON y están bajo el prefijo /api.

Método Ruta Descripción
GET /api/products Obtiene el listado completo de insumos dentales.
POST /api/products Crea un nuevo producto en inventario.
GET /api/categories Obtiene las categorías registradas.
POST /api/movements Registra una entrada o salida de stock.

💻 Frontend: Estructura de Servicios

El cliente consume la API mediante Axios estructurado en la carpeta src/services/:

  • api.ts: Configuración base con URL de Axios (http://127.0.0.1:5000).
  • productService.ts: Métodos getProducts y createProduct adaptados a los tipos de TypeScript.
  • App.tsx: Vista principal del inventario, tabla interactiva y modal de alta.
